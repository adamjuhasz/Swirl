# Swirl

An Expo React Native application.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm start
   ```

3. Run on specific platform:
   - iOS: `npm run ios` (requires macOS)
   - Android: `npm run android`
   - Web: `npm run web`

## Tech Stack

- **Expo SDK**: ~54.0.23
- **React**: 19.1.0
- **React Native**: 0.81.5
